# js-form-validation

<p>js-form-validation is a form validation application written with HTML5, CSS3, and vanilla JavaScript. It is an interactive form validation with responsive Flexbox and Grid layout, real-time key event feedback, and custom animated notifications for clear user guidance.</p>

## Features
- [x] Customizable
- [x] Lightweight
- [x] Responsive
- [x] HTML5
- [x] CSS3
- [x] JavaScript
- [x] Custom Notifications
- [x] Regular Expressions
- [x] Normalize.css
- [x] Google Fonts
- [x] Mobile Friendly
